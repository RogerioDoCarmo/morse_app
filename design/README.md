# Design

UI design phase for the Morse translator, run before any scaffolding (see `../AGENTS.md`).

## Direction — chosen 2026-08-21

**D · Practice Deck**, with a modern execution. The four candidates are in `options/`.

| | Direction | |
| --- | --- | --- |
| A | Telegraph Desk | paper, brass, inked marks |
| B | Signal Lamp | dark instrument, amber pulse |
| C | Dot & Dash | oversized marks, editorial |
| **D** | **Practice Deck** | **cards, learning-forward — chosen** |

## Files

`*.dc.html` are Design Component artboards — the editable source of the design canvas.
`canvas.json` lays them out and picks the launch view.

Edit the `.dc.html` files, then re-seed the canvas with the `design` skill's helper and
republish to the same artifact URL. Never hand-edit the seeded output.

## Settled at sketch time

- Phone **and** tablet layouts
